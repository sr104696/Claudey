## QUERY OPTIMIZATION TIPS

1. **Use site: operator** to limit to specific domains
2. **Combine OR terms** to capture variants: "legal counsel OR attorney OR compliance"
3. **Include location** when relevant: "New York" or "Remote"
4. **Add context terms** for better targeting: "fintech", "payments", "regulatory"
5. **Prioritize high-yield sources** based on historical results
6. **Rotate queries** to avoid pattern detection by search engines
7. **Monitor query effectiveness** and remove low-performing queries
8. **Add negative terms** to exclude irrelevant results: "-paralegal -document review"

## NOTES ON IMPLEMENTATION

1. These queries are designed for use with Google Custom Search or similar search APIs
2. In the current implementation, Claude runs these searches via WebSearch tool
3. Results are imported using `python -m radar import-leads <file> --source websearch:...`
4. For direct implementation, consider using:
   - Google Custom Search JSON API (free tier: 100 queries/day)
   - Bing Search API (free tier available)
   - DuckDuckGo API (no rate limits)
   - SerpAPI (paid, but comprehensive)

5. Remember to respect:
   - Rate limits of search APIs
   - robots.txt of target sites
   - Terms of service of job boards
   - Copyright and data usage policies
